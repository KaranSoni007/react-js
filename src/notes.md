# JSX : JavaScript Syntax Extension / JavaScript XML
It is a syntax extension for JavaScript that lets us to write the HTML like markup inside a JS file.

# JS + HTML = REACT JS

JSX allows to write HTML inside JS file

# Controlled Components:
It is a form whose input field value is controlled by React's state

For storing the value, we must use state in controlled components

We get the value of input field on onChange event rather than getting it on onSubmit

# Component LifeCycle
1. Mounting : Birth/Visible on screen as UI

2. Updating : Grow

3. Unmounting : Death/Remove from UI
